# LOGIFY Public Evidence

LOGIFY의 연구·설계·명세·구현 과정에서 생성된 **공개 가능한 검증 자료(Public Evidence)**를 선별하여 기록합니다.

## Purpose

이 저장소의 목적은 LOGIFY의 전체 내부 방법론이나 구현 방식을 공개하는 것이 아니라,

> 문제를 정의하고  
> 도메인을 구조화하고  
> 소프트웨어로 명세하고  
> 실제로 구현하고 검증할 수 있다는 것을

공개 가능한 산출물로 보여주는 것입니다.

## Evidence

향후 다음 자료가 순차적으로 추가됩니다.

- Problem / Domain Definition
- High-level Models
- Selected Specifications
- Synthetic / Sanitized Cases
- API Examples
- Implementation Evidence
- Verification / Test Results
- Demo Artifacts

## Projects

### HAM — Human Art Museum

자전적 경험과 관련된 개인 도메인을 탐구하는 LOGIFY의 대표 연구·제품 프로젝트입니다.

### Design Ontology

도메인 관찰과 추론을 명시적인 모델과 소프트웨어 명세로 연결하는 작업 방법론입니다.
